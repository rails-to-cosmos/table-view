* Proposals (deferred work)

Ideas surfaced but intentionally not built yet, each with enough design to pick
up later.

- [[file:proposals/incremental-render-o1.org][Incremental render → O(1) via mutator hints]] :: make streaming
  edits O(changed) instead of O(rows).
- [[file:proposals/incremental-width-maintenance.org][Incremental column-width maintenance]] :: avoid the full width
  recompute when a max-holding row changes.
- [[file:proposals/select-all-matching.org][Bulk “select all matching” (server pagination v2)]] :: act on the
  whole filtered result set without loading it.
- [[file:proposals/native-backend.org][Native data backend (tvx)]] :: a Rust background process as a fast
  local =page-fn= over =jsonrpc.el= for 100k–1M rows.
